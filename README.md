# OpenGrade(开元智阅)

> 把成绩还给教育,让阅卷回归教学。

新一代 **答题卡设计 → 扫描解析 → 极速阅卷 → 统分讲评 → 纵向学情** 一体化基础设施。
采用 **Open-Core(开源内核 + 商业增值)** 双轨模式:

- **开源社区版(本仓库)**:单校/年级完整可用,完全免费,数据 100% 本地化,零第三方依赖;
- **商业企业版**:多校联考调度、双评仲裁、AI 深度阅卷与讲评课件、信创私有化交付(见 [docs/roadmap.md](docs/roadmap.md))。

我们坚决不做"向家长收查分费"的模式:基础查分与答卷回溯免费开放,原始数据归属学校,随时可整包导出。

### 快速上手

```bash
# 1. 出卡:v2 版式(内置示例 30 客观 + 3 主观),或 -layout-file 传入自定义版式
ogctl gen -o og_out -layout-file my-layout.json -students 30
#   og_out/sheet.svg          ← 可打印矢量母版(浏览器打开直接打印 A4,支持中文卷头)
#   og_out/sheet.layout.json  ← 开放版式格式(读卡/切片的几何契约)

# 2. 读卡:任意尺寸扫描件/照片,自动旋转/透视矫正;强阴影场景加 -threshold adaptive
ogctl read -layout og_out/sheet.layout.json -image scan.jpg -out r.json

# 3. 主观题切片(离线路径)
ogctl slice -layout og_out/sheet.layout.json -image scan.jpg -o slices/

# 4. 统分 + 讲评建议(得分率 < 60% 的题目自动列出)
ogctl score -key og_out/key.json -results "r*.json"
```

**学情分析(对齐智学网报表维度,数据全在本地)**:教师工作台「学情分析」页给出
均分/最高/最低/中位数/标准差、及格率/优秀率/低分率、分数段分布柱状图、
逐题难度系数与区分度、客观题选项人数分布、班级对比;并可一键把原始分按
**新高考等级赋分**换算成赋分成绩(五等 / **21 级细分档**两种方案)。

**知识点掌握度(学情产品的数据地基)**:设计器建卡时逐题填写知识点标签
(多个用 `,`/`、` 分隔),学情分析页自动聚合出**班级知识点掌握度横条图**
(分值加权,薄弱点排前),可随时补录/修正标签并留痕审计;
成绩册 xlsx 追加「知识点」工作表。学生端同步给出**个人掌握度雷达**,
只统计有作答的题(未答不稀释分母)。

**错题重组练习卡(差异化闭环)**:学生端一键把本场错题/丢分题反向编译成
一张**新的答题卡版式**(保留题型/分值/知识点,不留考号区),在线预览并打印再练
(`GET /student/exams/{id}/practice.svg` 直接出可打印图,不借道任意版式渲染接口);
教师端「学情分析」页有**错题重练卡**面板,可选任一生生成
(`GET /exams/{id}/practice?student=N` 出重组版式,交 `/api/v1/cards` 渲染打印)。
同一版式几何可继续被 OMR 识别,天然衔接"练→批"闭环。

**考号码制通道(上量学校的硬门槛)**:设计器一键切换考号通道——填涂(默认)/ Code128 条码 / 二维码 / 双通道(填涂+码)。码印在卷头右侧并附明文考号兜底;OMR 在透视矫正后的标准网格上解码(条码多扫描线投票 + mod-103 校验,二维码 RS 纠错),**以码为准自动修复涂卡漏涂/多涂**,来源(`regSource`)与不一致告警全程留痕。纯手写实现,零第三方依赖。

**走班排考(新高考 3+1+2)**:名册与账号支持「行政班|教学班」双归属;教师可见性按班级集合交集判定;班级统计双口径(同一学生计入每个所属班);按教学班分配阅卷只见该班卷。**考场编排**:同班聚齐或纯考号序自动分场,座位点击对调、监考下拉指派,一键打印座位表,方案落盘重启不丢。

**场次表与监考冲突**:admin 在组织架构处维护全校场次表(如 第1节 08:00-09:30);考试挂场次后,
同一天同一场次的不同考试若指派了同一监考教师,考场编排页自动红标并列出冲突清单(只提示不阻断,教务自行改人)。

**AB 卷(同场两套卡防抄袭)**:建考上传 B 卷版式(客观题序可打乱,主观题区两版强制一致)+ 卡面序答案 + 题序对照;
卡面印卷种点(A/B 实心位不同),个性化卡二维码含「考试短号+卷种位+考号」——扫描时自动核对归属、自动分版判读,
B 卷作答入库即归一为规范题号(统计/导出/趋势与单卷完全同口径);卷种判不出的卷暂扣客观题,异常清单一键指派重读;
「打印 A/B 卷」按名册逐生出个性化卡 PDF。

**手机/平板阅卷**:Grader 工作台 ≤860px 自适应(切图在上、操作区在下),画笔触屏可用,
打分/标记/导航全部可点 —— 手机上也能评卷(桌面键盘盲操体验不变)。

**多页版式**:A4 装不下不再报错——主观题自动分页,每页重印标题、页码、考号与条码/二维码,可逐页独立扫描归属;设计器预览可切换页签。**按页考号归组**(现实对齐批):上传不再要求"每生连续 N 页"凑整数倍——服务端逐页判读考号与**页点页号**(卷头右上第 k 点实心=第 k 页),按考号分组、按页号合并;扫描仪卡纸跳页只产生「考号 XXX 缺第 2 页」的页级告警,不再把后面所有学生的页全部错位;乱序上传自动归组自愈。

**评分颗粒度(现实对齐批)**:17 分大题、作文 60 分、0.5 步进——打分不再被封顶在 10:满分 ≤10 数字键即打即存;更大满分自动变「十位行+个位行」两键合成(`1`→`2`=12 分),输入条支持两位数与小数回车直录,`±0.5` 修正键处理半分;服务端同步校验,负分/超满分(含小问满分)直接拒绝。

**卷生命周期(现实对齐批)**:扫糊重扫、重复上传不再"只进不出"——异常卷可**作废/恢复**(作废卷不进报告/统计/阅卷队列,可随时恢复);同考号多份卷自动聚组,「保留卷 N」一键裁决重扫替换。

**考试元数据与年级总表(现实对齐批)**:考试带日期/学期/类型/同场分组;列表可按学期/类型过滤、按考试日期排序。同一次考试的多科填同一「同场分组」标签,「年级总表」页聚合出**年级总分工表**——各科得分+总分+年级排名(并列同名次)+班级排名,缺考计 0,**全科缺考默认不参与排名**(可切换为计 0 垫底的旧口径),一键导出 CSV;账号看不全分组科目时页面明示「总分仅按可见科目」;这是教务用阅卷系统的第一张表。

**手工成绩科目(现实对齐批)**:体育、实验、听力、纯纸笔考试免版式建考(学科+满分+名册),教师逐格直录分数或粘贴 Excel 两列批量导入;统计/趋势/年级总表与扫描科目完全同口径。

**成绩复核申请(现实对齐批)**:发布后学生/家长可对某场考试发起复核申请(填理由),教师在考试详情回复结论并标记处理,学生端可见回复——"家长来问分"不再是教师自己翻卷。

**扫描导入(现实对齐批)**:高速扫描仪的多页 **PDF 直接拖入**(内置 pdf.js 本地拆页,离线可用);大批量前端自动按 15 张分批接力上传,带进度与断点提示。

**量产质检**:同一考号二次扫描自动告警「疑似重答」(建考批内 + 补传对存量),全卷未作答告警「疑似空白卡」,统一进考试详情异常清单;题库题被哪些考试用过自动回记;成绩册 xlsx/csv 补姓名/班级列。

**阅卷治理与数据安全(现实对齐批)**:考试可开**匿名阅卷**(阅卷端不显示考号);评分带**乐观锁**(双开互踩 409 提示刷新);**全班成绩条连排 PDF**(每页 2 张带裁切线与家长签字线,家长回执一次打印;排名与均分恒为全卷口径);任务可设**截止时间**(我的任务过期标红)并有**工作量统计**(按教师聚合已评仂数);`data/` 下全部 JSON **每 12 小时自动备份**(保留最近 10 份);初始管理员、管理员重置密码与批量开号的新账号都**强制改密**——服务端闸门,改密前仅放行改密端点。

**纵向学情(跨考试不再孤岛)**:「纵向趋势」页按考号把历次考试对齐到同一条时间轴——
班级均分走势、逐生最近得分/名次/**名次进退步**("这次比上次退步了 15 名")、
个人得分率曲线与班级对照线;学生/家长端有按学科分组的**历次成绩趋势**
(得分率跨卷满分可比,缺考场次断点呈现)。缺考学生保留对齐行但不计入统计与排名。

**扫描与补录的补救语义(量产阅卷的实操兜底)**:建考后中途扫完的一批卷直接
「补传扫描」续接同一会话(逐卷判读失败不阻塞整批);漏扫/答题卡作废的学生按考号
**手工补录**(手输客观题作答,卷号续排,主观题照常评分);已扫卷可事后
**标记缺考**——统计、排名、选项分布、赋分自动剔除,成绩册中保留"缺考"标记。

**版式 v3 小题切片(高中阅卷真实形态)**:设计器里给一道大题填"拆小问分值"(如 `6,5,6`),
答题卡作答区右上角印逐问得分框;Grader Studio 逐问打分(`0-9` 打当前问,自动跳下一问,
`Space` 当前问满分),大题总分自动求和——**全部小问阅完才计入统计**(半阅不进均分);
学情分析与成绩册细目表给出逐问均分/得分率。未拆分的题目与 v1/v2 旧版式完全兼容。

**版式 v3 选做题题号区(如"32、33 二选一")**:设计器给同组互斥的题填同一"选做组"标签(2~4 道),
卡面在该组第一道题的标签行右端印**题号区涂点**;学生涂所选的题号,OMR 判读后统分
**只取所选**——唯一涂选计所涂题;漏涂/多涂时组内恰有一题已批阅则取该题(教师批了学生实际作答的那题),
否则整组不计分。该题统计分母为**实际选做人数**,卷面满分每组只计一题;
切片工作台显示该生涂选与判分计入题,学生端把未选题标注"未选做,不计分"。

**校本题库(学校自录题,题库地基最小版)**:教师工作台「题库」页录入本校题目
(题干/参考答案/知识点/难度先验,数据在本机 `data/bank.json`);设计器「从题库选题」
把题目插入答题卡版式,**题型/选项/分值/知识点随题带出**,客观题参考答案一键按题序生成——
不再逐题手填。试卷识别的题目可连**题干截图**一键入库,题库列表与选题器显示缩略图。
后续个性化推题、变式训练以这份"题 → 知识点/答案"数据为共同底座。

**账号批量导入**:用户管理页粘贴或上传 CSV(Excel「另存为 CSV UTF-8」),

产品红线:基础查分与答卷回溯不收费、不设卡,学生只能看到本人数据。

1. **设计答题卡**:混排客观题(单选/判断/多选)+ 主观题留白区,实时预览,下载可打印 SVG;
   **从试卷扫描识别版式(半自动出卡)**:上传普通试卷照片/扫描件 → 纯 Go 版面分析自动检测题目构成
   (题型/选项数/题号连续性审计/留白高度,支持单栏与标准双栏、判断题印 A/B 或「对/错」、照片自动裁纸面)
   + 每题题干截图,确认页逐题微调后出卡,一键导入题库;
2. **建考与阅卷**:粘贴版式与参考答案、上传学生名册(可选)与多张整卷扫描件 → 服务端 OMR + 切片 + 整卷回溯图;
3. **Grader Studio 阅卷工作台**(`/grader.html?exam=<id>`):切片预加载流水线、
   全键盘盲操(`0-9` 打分,大题十位+个位两键合成 / `.`+`Enter` 小数 / `Space` 满分 / `Z` 零分 /
   `V`✓ `B`✗ `X`⚑ / `P` 画笔 / `±0.5` 半分 / `Enter` 切卷)、
   手写批注笔迹(随评分持久化)、切片放大与灰度/反色增强、
   **异常卷考号推荐指派**(漏涂/多涂时按名册"可读位匹配"给候选,一键确认)、进度条、统分报告;
4. **教师工作台**(`/teacher.html`):考试列表、**阅卷任务分配**(组长/管理员把主观题分派给教师)、
   班级报告(班级对比统计)、成绩册/讲评课件/数据包导出;
5. **用户管理**(`/admin.html`,管理员):教师/组长/学生账号增删改、密码重置;
6. 一键交付:成绩册 `.xlsx`(成绩单含排名/缺考标记 + 细目表含难度/区分度/选项分布)/`.csv`、
   **讲评课件 `.pptx`**、**全量数据包 `.zip`**(开放数据协议 v1);
7. 数据全部落在本机 `data/` 目录,可整目录拷贝迁移。

### 中文字体(零依赖实现)

位图渲染路径通过内置的**最小 TrueType 解析器 + 光栅化器**直接使用本机系统中文字体
(Windows 微软雅黑/黑体、macOS 苹方、Linux Noto CJK/文泉驿,可用 `OPENGRADE_FONT` 指定),
无需安装任何第三方库;找不到字体时自动退化为内置点阵(SVG 打印路径始终支持中文)。

## 核心设计:为什么它比传统产品更稳

**几何同源**。出卡与读卡共享同一份版式模型(`card.Layout`):设计器排出的每一个涂卡圆、
每一道主观题作答区,识别/切片引擎按同一坐标处理,不存在"Word 模板错位一毫米就识别歪"的问题——
因为根本没有两套模板。

**高容错识别**。`omr` 内核流程:二值化(全局 Otsu 或积分图 Bradley 局部自适应)→ 四角实心方块定位
(连通域 + 实心度/尺寸/象限先验)→ 单应变换透视矫正 → 按共享几何判读。扫描件无论旋转、歪斜、
光照不均,一律先矫正回标准版面再判读。定位带五级兼容层:标准闸门 → 比例自校准(打印缩放/扫描
DPI/照片留白)→ 多尺度实心窗模板(粘连/裁切)→ 位置吸附 → 相邻角标几何推算(整角遮挡/裁没
不硬失败,考号失准走异常清单人工指派),并防涂卡圆、QR finder、码区图形的假角标。
`synth` 包是这套引擎的"容错靶场",持续用它做回归验证。

**数据属于学校**。版式、答卷、成绩、报告、切片全部是开放的 JSON/PNG 文件,存放在学校自己的机器上,
没有任何厂商云端依赖;导出即迁移,无锁定。

## 目录结构

```
auth/    账号与角色权限:PBKDF2 口令散列、会话、四级角色(admin/leader/teacher/student)
card/    答题卡版式模型 v2(几何真源,题型化)+ SVG/PNG 双渲染器(中文位图)
font/    零依赖 TrueType 解析器 + 光栅化器 + 系统中文字体发现
omr/     高容错 OMR 内核:自适应二值化/定位/单应矫正/判读 + 考号逐位明细 + 主观题切片
roster/  学生名册 + 考号"可读位匹配"推荐(异常卷自愈)
score/   统分:客观对分 + 主观人工分合并(含手写批注笔迹),逐题得分率
export/  交付物生成:成绩册 xlsx/csv、讲评课件 pptx(纯 zip+xml 零依赖)
synth/   模拟扫描损伤(容错靶场)
raster/  零依赖像素绘图库(内置 5x7 点阵字体 + 覆盖度混合)
cmd/     ogctl 命令行工具、ogserver HTTP 服务(考试会话存储)
web/     登录页 + 设计器 + Grader Studio + 教师工作台 + 学生查分页 + 用户管理(零构建原生 JS)
docs/    产品方案存档、架构说明、路线图
```
