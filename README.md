# OpenGrade(开元智阅)

> 把成绩还给教育,让阅卷回归教学。

新一代 **答题卡设计 → 扫描解析 → 极速阅卷 → 统分讲评 → 纵向学情** 一体化基础设施。
采用 **Open-Core(开源内核 + 商业增值)** 双轨模式:

- **开源社区版(本仓库)**:单校/年级完整可用,完全免费,数据 100% 本地化,零第三方依赖;
- **商业企业版**:多校联考调度、双评仲裁、AI 深度阅卷与讲评课件、信创私有化交付(见 [docs/roadmap.md](docs/roadmap.md))。

我们坚决不做"向家长收查分费"的模式:基础查分与答卷回溯免费开放,原始数据归属学校,随时可整包导出。

## 当前进度:账号权限 + 学生端(社区版功能全量落地)

纯 Go、**零第三方依赖**、单二进制部署。已完成端到端验证:

```
出卡(v2 题型 + 中文字体位图渲染)
  → 模拟真实扫描损伤(透视 + 旋转 + 光照不均 + 噪声 + JPEG)
  → OMR:考号 5/5,客观涂卡判读 150/150 = 100%(含判断/多选题型)
  → 异常卷自愈:考号漏涂卷 → 名册"可读位匹配"推荐 → 一键指派
  → 主观题自动切片(矫正后裁剪)
  → Grader Studio 工作台:键盘盲操 + 手写批注 + 图像增强
  → 客观+主观合并统分 → 讲评课件 pptx + 成绩册 xlsx/csv → 全量数据包 zip
```

```bash
go build -o ogctl ./cmd/ogctl
./ogctl demo -o demo_output -students 5     # 一条命令看完整演示(含 review.pptx / report.xlsx)
```

### 快速上手

```bash
# 1. 出卡:v2 版式(内置示例 30 客观 + 3 主观),或 -layout-file 传入自定义版式
ogctl gen -o og_out -layout-file my-layout.json -students 30
#   og_out/sheet.svg          ← 可打印矢量母版(浏览器打开直接打印 A4,支持中文卷头)
#   og_out/sheet.layout.json  ← 开放版式格式(读卡/切片的几何契约)

# 2. 读卡:任意尺寸扫描件/照片,自动旋转/透视矫正;强阴影场景加 -threshold adaptive
ogctl read -layout og_out/sheet.layout.json -image scan.jpg -out r.json

# 3. 主观题切片(离线路径)
ogctl slice -layout og_out/sheet.layout.json -image scan.jpg -o slices/

# 4. 统分 + 讲评建议(得分率 < 60% 的题目自动列出)
ogctl score -key og_out/key.json -results "r*.json"
```

### 中文字体(零依赖实现)

位图渲染路径通过内置的**最小 TrueType 解析器 + 光栅化器**直接使用本机系统中文字体
(Windows 微软雅黑/黑体、macOS 苹方、Linux Noto CJK/文泉驿,可用 `OPENGRADE_FONT` 指定),
无需安装任何第三方库;找不到字体时自动退化为内置点阵(SVG 打印路径始终支持中文)。

## 核心设计:为什么它比传统产品更稳

**几何同源**。出卡与读卡共享同一份版式模型(`card.Layout`):设计器排出的每一个涂卡圆、
每一道主观题作答区,识别/切片引擎按同一坐标处理,不存在"Word 模板错位一毫米就识别歪"的问题——
因为根本没有两套模板。

**高容错识别**。`omr` 内核流程:二值化(全局 Otsu 或积分图 Bradley 局部自适应)→ 四角实心方块定位
(连通域 + 实心度/尺寸/象限先验)→ 单应变换透视矫正 → 按共享几何判读。扫描件无论旋转、歪斜、
光照不均,一律先矫正回标准版面再判读。`synth` 包是这套引擎的"容错靶场",持续用它做回归验证。

**数据属于学校**。版式、答卷、成绩、报告、切片全部是开放的 JSON/PNG 文件,存放在学校自己的机器上,
没有任何厂商云端依赖;导出即迁移,无锁定。

## 目录结构

```
auth/    账号与角色权限:PBKDF2 口令散列、会话、四级角色(admin/leader/teacher/student)
card/    答题卡版式模型 v2(几何真源,题型化)+ SVG/PNG 双渲染器(中文位图)
font/    零依赖 TrueType 解析器 + 光栅化器 + 系统中文字体发现
omr/     高容错 OMR 内核:自适应二值化/定位/单应矫正/判读 + 考号逐位明细 + 主观题切片
roster/  学生名册 + 考号"可读位匹配"推荐(异常卷自愈)
score/   统分:客观对分 + 主观人工分合并(含手写批注笔迹),逐题得分率
export/  交付物生成:成绩册 xlsx/csv、讲评课件 pptx(纯 zip+xml 零依赖)
synth/   模拟扫描损伤(容错靶场)
raster/  零依赖像素绘图库(内置 5x7 点阵字体 + 覆盖度混合)
cmd/     ogctl 命令行工具、ogserver HTTP 服务(考试会话存储)
web/     登录页 + 设计器 + Grader Studio + 教师工作台 + 学生查分页 + 用户管理(零构建原生 JS)
docs/    产品方案存档、架构说明、路线图
```
