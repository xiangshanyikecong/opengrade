# 与智学网功能对齐:差距分析与缺口清单

> 基准:智学网(科大讯飞)单校/区域考试全流程产品能力。
> 现状核对:代码实际实现(2026-10,commit 4d360fb),而非方案稿口号。
> 轨道标注:**CE** = 开源社区版必须对齐;**EE** = 商业企业版对齐;**✗** = 刻意不对齐(产品红线/版权边界)。

## 结论先行

阅卷主流程(出卡→扫描→判读→切片→评分→统分→导出)社区版已闭环。真正拉开差距的是三块:

1. **统计分析深度**——智学网的学情报表有十几个维度,`score.Report` 现已覆盖排名、标准差/中位数、及格率、分数段、难度、区分度、选项分布、**知识点掌握度**;仍缺信度/效度、增值评价、目标生跟踪。
2. **题库与知识点体系**——智学网一切学情产品(知识点雷达、个性化推题、讲评)背后是题库+知识点树这张"隐形发动机"。**知识点标签体系已上线**(建考逐题录入→班级/个人掌握雷达);**校本题库最小版已上线**(`data/bank.json` 学校自录题:题干/答案/知识点/难度,教师工作台管理 + 设计器选题带入题型/答案/知识点),个性化推题、变式训练、题目与考试历史关联仍开放,但共同数据底座已就位。
3. **量产阅卷机制**——双评仲裁、回评、质检、客观题人工修正补录,这些是区级考试的准入门槛(补录/缺考/答案修正已落地,双评仲裁仍属 EE)。
4. **新高考场景**——等级赋分(五等 + 21 级细分档)、选做题题号区、走班排考(双归属+考场编排)均已上线。

> **2026-10 更新**:G1(统计引擎)、G3(答案修正重统+审计)、G6(发布控制+家长关联+成绩报告单)、G7(排名/班级排名)已随 M3/M3.5 落地;G7 的"多试纵向对比"已上线(教师端 `/api/v1/trends` + 学生端 `/api/v1/student/trends`,名次进退/均分走势/个人曲线);扫描通道补传(`POST /exams/{id}/scans`)与手工补录/缺考标记(`/manual`、`/absent`)已落地,成绩册细目表补齐难度/区分度/选项分布列;G5 的小题切片已上线(版式 v3 `SubjectiveSpec.Parts`,逐问给分自动汇总,工作台键盘跳问),账号 CSV 批量导入已上线。**最新一批已上线**:G2 知识点体系最小版(建考逐题标签 → 班级掌握度横条 + 学生个人雷达 + xlsx「知识点」表)、G6 补完(服务端 PDF 成绩报告单)、G8 错题重组练习卡(错题本反向编译新版式,教师/学生双入口)、G5 补完(主观题按班分配与按题并存)、赋分 21 级细分档、**选做题题号区**(版式 v3 `SubjectiveSpec.Elective`:卡面题号区涂点,判分只取所选,漏涂/多涂按批阅回退,选做人数进统计与细目表)、**校本题库最小版**(`data/bank.json` 学校自录题 + 设计器选题带入)。**仍开放**:批量扫描仪驱动(TWAIN)、AB 卷密钥、一卡多人、自由拖拽设计器。**本批已上线**:考号码制通道(Code128 条码 + 二维码,双通道可修复涂卡漏涂)、走班排考(双归属+统计双口径+按教学班分配+考场编排落盘微调打印)、重答/空白卡检测、题库-考试使用史、成绩册姓名/班级列、OMR 定位鲁棒性加固。**流程阶段化批次(2026-10-24)已上线**:建考/扫描解耦(建考=建档,扫描件与答案皆可后补)、考试状态机(待扫描→扫描中→异常待处理→阅卷中→待发布→已发布,数据派生)、考试详情枢纽(扫描会话内联反馈+缺扫名单+异常清单逐条裁决+⚑待复核队列+逐题进度)、教师「我的任务」默认页(按题/按班/建卷人聚合,`GET /api/v1/my/tasks`)、组织架构 `data/school.json`(年级↔班级;年级组长按年级收敛)、班主任(本班全科)/学科组长(本学科跨班)权限口径、建考从班级选名册(学生账号带出)。

## 三、题库问题的务实解法(避免掉进大坑)

完整题库+组卷是讯飞十几年资产,社区版不追。最小可行(✅ **v1 已落地**):
