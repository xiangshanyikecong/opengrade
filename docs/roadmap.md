# OpenGrade 路线图

与产品方案稿(见 [product-plan.md](product-plan.md))的三阶段 GTM 对齐,工程上拆为 M0~M6。

## M0 开源内核 CLI + API(✅ 已完成)

- [x] `card` 版式模型:容量校验、mm→px 几何编译、SVG 打印母版 + 300 DPI PNG
- [x] `omr` 高容错读卡:Otsu 二值化、四角方块定位、单应透视矫正、涂卡/考号判读、调试叠加图
- [x] `score` 统分:成绩单、逐题得分率、讲评关注题筛选
- [x] `synth` 容错靶场:透视/旋转/光照/噪声/JPEG 合成扫描
- [x] `ogctl` CLI(gen / read / score / demo)与 `ogserver` 三个原子 API
- [x] 验收:畸变扫描下考号与涂卡判读 100%(demo_output 可复现)

## 验收基线(持续)

- `go test ./...`:单元 + 畸变 roundtrip 全绿(v1 等权重卷与 v2 混题型卷各一);
- `ogctl demo`:随机种子遍历 50 组,考号/涂卡判读准确率 ≥ 99.5%;
- 真实扫描样本库:每个主要机型 ≥ 200 张,准确率 ≥ 99.9%(M1 起)。

- [x] CJK 位图渲染:内置最小 TrueType 解析器 + 光栅化器,运行时自动发现系统中文字体(零依赖)
- [x] 局部自适应二值化(积分图 Bradley,强阴影/翻拍场景)
- [x] 主观题切片器:`omr.SliceRectified`(矫正图按共享几何裁剪)+ CLI `ogctl slice`
- [x] 考试会话存储层(data/ 目录 JSON + PNG,重启恢复;SQLite 迁移待引入依赖评审)
- [x] Web 可视化设计器:混排题型段落编辑、实时预览、SVG 下载(完整拖拽自由排版仍开放)
- [x] 异常卷自愈 v0:OMR 考号逐位判涂明细 + 名册"可读位匹配"推荐 + 工作台一键指派/搜索
- [x] 班级报表:成绩册 xlsx(成绩单+细目表)/csv 导出、合并统分报告
- [x] 一键全量数据打包导出(切片原图 + 细目表 + 打分日志,开放数据协议 v1)

- [x] 学生端:免费查分、逐题对错与错题本、主观题切片与整卷答卷回溯(仅本人可见)

- [x] 教师数据范围:任教班级 ∧ 任教学科(报告/导出过滤,阅卷跨班,主任/管理员全看)
- [ ] 真实扫描仪样本回归库(通用 TWAIN/SANE/复合机兼容矩阵)

## M3 校级产品化(方案稿第 2 阶段前端)

- [ ] 异常卷自愈:考号漏涂/错涂 → 学籍名册模糊匹配推荐(手写姓名 OCR)
- [ ] 多场考试管理:建考后补传扫描件续接同一会话(`POST /exams/{id}/scans`,逐卷判读失败不阻塞整批)
- [x] 班级报表与无锁死原始 Excel 导出
- [x] 一键全量数据打包导出(切片原图 + 细目表 + 打分日志,开放数据协议 v1)
- [x] 条形码/二维码卷号识别(考号五通道:填涂 / Code128 条码 / 二维码 / 填涂+条码 / 填涂+二维码双通道)
    - 版式 v3 `Layout.RegMode`:码区印在卷头右侧(条码含明文考号兜底),设计器下拉选择,`ogctl gen -reg-mode`;
    - 全链路判读:omr 在透视矫正后的标准网格上解码(条码多扫描线投票 + mod-103 校验;二维码 RS 纠错 v1~v4),
      以码为准修复涂卡漏涂/多涂,`Result.RegSource` 记录来源,不一致告警进异常清单;
    - 新增零依赖 `barcode/`(Code128 编解码)与 `qrcode/`(QR 数字模式编解码)两个包;
    - 定位鲁棒性加固:稀疏版面 Otsu 失衡时自动回退局部自适应/墨迹百分位阈值,实心度阈值 0.85→0.80 + 两维尺寸双闸门
- [x] 成绩发布控制(教师确认后发布,未发布学生/家长不可查)+ 家长账号关联(仅见绑定子女)
- [x] 学生个人成绩单回执(浏览器打印版报告单;服务端 PDF writer 待做)
- [x] 手工补录与缺考标记:漏扫/答题卡作废按考号补录(卷号续排)、已扫卷可标记缺考;统计/排名/选项分布自动剔除缺考(`POST /exams/{id}/manual`、`POST /exams/{id}/absent`)
- [x] 教师/学生账号 CSV 批量导入(`POST /api/v1/users/import`,Excel 另存 CSV UTF-8;已存在账号仅更新行内非空字段;班级列支持 `行政班|教学班` 走班多班);改分与答案修正操作留痕(审计日志已上线)
- [x] 重答/空白卡检测:同考号二次扫描(建考批内与补传对存量)自动告警「疑似重答」,全卷客观题未作答告警「疑似空白卡」,进考试详情异常清单(`examDetail.warnings`)
- [x] 成绩册导出补姓名/班级列:xlsx 成绩单与 CSV 增加「姓名」「班级」列(走班多班用 `|` 连接),按名册自动注入

## M3.5 学情统计引擎(对齐智学网报表维度,见 [feature-gap-vs-zhixuewang.md](feature-gap-vs-zhixuewang.md))

- [x] `score` v2:班/年级排名(并列名次)、中位数/标准差/极差、及格率/优秀率/低分率(60/85/40% 默认阈值,按比例线)
- [x] 客观题选项人数分布(含"未答")进入 Report API 与逐题分析
- [x] 小题难度系数(=得分率)与区分度(27% 高低分组差)
- [x] 建考录入"逐题知识点标签" → 班级/个人知识点掌握雷达(标签存于会话,`card.QuestionSpec/SubjectiveSpec.Knowledge`;班级掌握度=分值加权得分率,学生端个人掌握度只统计有作答的题;xlsx 追加「知识点」表)
- [x] 新高考等级赋分转换(3+1+2 默认五等,A15/B35/C35/D13/E2,区间内线性插值,同分同赋;**21 级细分档** `score.FineGradeScale`,等级内 3 分一档,`{"fine":true}`)
- [x] 客观题标准答案修正 → 全班重统(管理员/组长/建卷教师);评分改分审计留痕
- [x] 前端:分数段柱状图(原生 canvas)、统计卡片、逐题分析表、赋分对照表、审计页、知识点横条图与标签编辑器
- [x] 服务端个人成绩报告单 PDF(零依赖手写最小 PDF + raster/font 渲染位图,`GET /api/v1/student/exams/{id}/report.pdf`)
- [x] 多试纵向对比:同名学生跨考按考号对齐,名次进退/均分走势
    - 教师端「纵向趋势」页(`GET /api/v1/trends?class=&subject=`):班级均分走势图、考试序列、逐生最近得分/名次/进退步、个人得分率曲线(与班级对照);
    - 学生/家长端「历次成绩趋势」(`GET /api/v1/student/trends`):按学科分组的成绩曲线、班级均分对照线、名次进退(仅已发布考试);
    - 缺考学生保留对齐行但不计入统计/排名,曲线断点呈现(`score.Absent` 语义)。

## M3.6 高中阅卷形态(版式 v3)

- [x] 小题切片:一道大题拆多小问独立给分(`SubjectiveSpec.Parts`),自动汇总到大题总分
    - 版式:作答区右上角逐问得分框,标签行印分值拆解(如 17 分=6+5+6);切片按大题裁剪,工作台逐问打分(键盘自动跳问);
    - 统分:全部小问已阅才计入大题(半阅不进统计),`QuestionStat.Parts` 逐问均分/得分率进报表与细目表子行;
    - 未拆分题型完全兼容(v1/v2 版式与既有考试不受影响)。
- [x] 主观题按班分配(班主任改本班)与按题分配并存(`Exam.TaskMode`/`ClassTasks`;按班分配后被分教师只见本班卷,管理员/组长全量)
- [x] 选做题/题号区(如"22、23 二选一"):版式 v3 `SubjectiveSpec.Elective` 选做组,卡面在组内第一道题标签行右端印题号区涂点,
    OMR 判读涂点(`omr.Result.Electives`),统分"判分只取所选"——唯一涂选计所涂题,漏涂/多涂时组内恰一题已批阅则取该题,
    否则整组不计;选做人数为该题统计分母,卷面满分每组只计一题;切片工作台/学生端/报告单/细目表/xlsx 同口径呈现
- [x] 走班排考:学生教学班/行政班双归属,考场编排(生成→微调→打印)
    - 数据模型:`roster.Student.Classes`(名册 CSV 第 3 列 `行政班|教学班`,Classes[0]=主班)、`auth.User.Classes`
      (账号导入班级列同口径);教师判定按「班级集合有交集」,统计双口径(同一学生计入每个所属班);
    - 考场编排:`Exam.Rooms` 落盘,`POST/PATCH/GET /exams/{id}/rooms`(同班聚齐/纯考号序分场、座位对调、
      监考指派、教师工作台「考场编排」页打印座位表;仅管理员/组长/建卷教师可变更);
    - 按教学班分配阅卷:被分教师阅卷流只见所分班级(多班教师不再按全部任教班放行)。
- [x] 校本题库最小版 `data/bank.json`(学校自录题:题干/参考答案/知识点/难度先验,`/api/v1/bank` CRUD;
    教师工作台「题库」页管理,设计器「从题库选题」插入版式并自动带出题型/选项/分值/知识点,
    客观题参考答案按题序一键生成;**题目与考试的历史关联已上线**:版式携带 `bankId`,建考自动回记
    `UsedIn`(去重),题库页显示「已用于 N 场」;变式推题仍开放)
- [x] 错题重组练习卡:错题本反向生成新答题卡(`GET /exams/{id}/practice?student=N` 与 `GET /student/exams/{id}/practice`;保留题型/分值/知识点,可打印再练)
