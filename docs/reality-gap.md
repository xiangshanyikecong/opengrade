# 与现实不匹配的差距清单(现实对齐批次)

> 与 [feature-gap-vs-zhixuewang.md](feature-gap-vs-zhixuewang.md)(对齐讯飞智学网)不同轴:本文记录"与学校真实操作不匹配"的问题——代码能跑、现实不能用或用着别扭的点。
> 状态:**本批(2026-10-24)全部落地**。逐项留档,防止回归时丢上下文。

## 一、与现实不匹配的情况(原始分析 + 落地结果)

### P0:会产生错误数据或堵死流程的

**1. 打分界面上限 10 分,且无半分 —— ✅ 已修复(评分颗粒度)**
- 原状:按钮 `min(10, 满分)`,数字键仅满分 ≤10 生效;17 分大题最多给 10 分,0.5 步进无处输入。
- 现状(Grader Studio 重构):
  - 满分 ≤10:数字键即打即存(原快路径不变);
  - 满分 >10:**十位+个位两键合成**(`1`→`2` = 12 分;`0` 开头给个位分),按钮组自动变「十位行 + 个位行」;
  - **小数**:输入条直接键入(0.5 步进)回车确认,或 `.` 键起缓冲 + `Enter` 提交;
  - **±0.5 修正键**在当前生效分上加减;
  - 服务端兜底:评分越界(负分/超满分,含小问满分)直接 400(`store.SetGrade/SetGradePart`),e2e 断言。

**2. 多页卷按"每 P 张连续"纯顺序切块 —— ✅ 已修复(按页考号归组)**
- 原状:整批张数须为页数整数倍,一页卡纸全批错位;分组不用每页已印的考号。
- 现状(`cmd/ogserver/pagegroup.go` 重写入库管线):
  - **逐页独立判读考号** → 按考号分组 → 组内按**页点页号**排序合并;
  - **页点标记**:多页卡卷头右上印一排小方块,第 k 点实心=第 k 页(card 渲染 SVG/PNG 双路径 + OMR 判读 `Result.PageNo`),机器可读页号;
  - **整数倍硬校验取消**:张数不再要求是 P 的倍数;扫描仪卡纸只影响对应学生;
  - **页级缺页告警**:「考号 02000002 的卷仅识别到 1/2 页(缺第 2 页——请补扫该页后重新上传)」;
  - 多页(重扫/夹页)告警;乱序上传 e2e 验证归组自愈(multipage_e2e_test);
  - 兼容回退:无考号通道版式 / 整批考号全不可读且恰为整数倍 → 退回位置分组。

**3. 卷子"只进不出" —— ✅ 已修复(卷生命周期)**
- 原状:重答/空白卡只能指派考号或标缺考;扫糊重扫的旧卷永远留在 Results。
- 现状:
  - **作废/恢复**:`POST /api/v1/exams/{id}/results/{student}/void`;作废卷不进报告/统计/阅卷队列/复核队列,卷位与评分键保留,随时恢复;异常清单行内「作废此卷」+ 详情页「已作废卷」列表;
  - **重复卷裁决**:同考号多份卷自动聚组(`duplicates`),详情页「保留卷 N」一键作废组内其余 —— 重扫替换的语义 = 传新卷 + 保留新卷;
  - 学生端语义:作废卷 = 这份卷不存在(`findIndex` 跳过),查分/回溯不可见。

### P1:与学校实际操作习惯冲突的

**4. 扫描件只收 PNG/JPEG —— ✅ 已修复(PDF 导入 + 分批接力上传)**
- **多页 PDF 拆页**:pdf.js(本地 `web/vendor/`,离线可用)客户端逐页渲染 ~1600px JPEG,自动并入上传队列;
- **前端自动分批**:每 15 张一批顺序接力 POST,「第 2/8 批…已入库 30 卷」进度;某批失败不丢已入库批次,修好后续传;
- 服务端 `/scans` 响应新增 `notes`(缺页/归组提示),详情页内联展示。

**5. 考试没有日期/学期/类型/同场分组 —— ✅ 已修复(考试元数据 + 年级总表)**
- `Exam` 新增 `ExamDate / Term / ExamType / ExamGroup`(建考表单填写,详情页「考试信息」可改,`POST /api/v1/exams/{id}/meta`);
- 列表按考试日期排序,新增学期/类型/分组筛选;
- **年级总分工表**(教务第一张表):`GET /api/v1/aggregate?group=同场标签` —— 同场多科聚合,一行一名学生:各科得分 + 总分 + 年级排名(并列同名次)+ 班排名,缺考计 0、不在册标「—」;教师端新增「年级总表」页(表格 + 各科均分走势 + CSV 导出);
- 纵向趋势轴改用考试日期(未填用创建时间)。

**6. 非答题卡成绩进不了系统 —— ✅ 已修复(手工成绩科目)**
- **免版式建考**:建考页勾选「手工成绩科目」→ 学科 + 满分 + 名册(必填),不渲染答题卡、无扫描环节;每位名册学生预建待录入卷;
- **直录分数**:考试详情「成绩录入」逐格打分(两位数/小数),或粘贴 Excel 两列(考号、成绩)一键导入(`POST /api/v1/exams/{id}/manual-scores`);缺考可标;
- 合成单题版式 → 统分/报告/导出/趋势/年级总表**全部复用既有机器**,体音美实验与扫描科目同口径。

**7. 没有学生复核/查卷申请通道 —— ✅ 已修复(成绩复核申请)**
- 学生/家长端(已发布考试):「成绩复核申请」→ 填理由提交(`POST /api/v1/student/exams/{id}/appeals`);
- 教师端考试详情「复核申请」列表:回复结论 + 标记已处理(`POST /api/v1/exams/{id}/appeals/{n}/resolve`),可深链去阅卷改分;学生端可见自己的申请与教师回复。

### P2:打磨级

**8. 匿名阅卷开关 —— ✅** 考试元数据开关;阅卷工作台隐藏考号(评完再对分),待复核队列同步匿名。
**9. 改分乐观并发控制 —— ✅** `Grade.Ver` 版本号随每次写入自增;`POST /grades` 携带 `ver`,不匹配 409 并返回服务器当前分,工作台提示后自动刷新(ver=0 兼容旧调用方不校验)。
**10. 全班成绩条连排批量打印 —— ✅** `GET /api/v1/exams/{id}/slips.pdf`:每页 A4 排 2 张成绩条,条间裁切线;含姓名/班级/考号/总分/年级班排名/均分/家长签字线,一次导出全班。
**11. 阅卷工作量统计 + 任务截止时间 —— ✅**
- 工作量:`GET /api/v1/workload` 按评分操作人聚合已评份数(评分记录新增 `By`),任务分配页展示(含 ⚑ 待复核与分布);
- 截止时间:按题/按班任务设截止日期(`TaskDue` + `POST /api/v1/exams/{id}/task-due`),「我的任务」过期未评完标红。
**12. data/ 自动备份 + 强制改密 —— ✅**
- 自动备份:启动即一次 + 每 12 小时,把 data/ 下全部 JSON(账号库/组织/题库/各考试 exam.json)快照到 `data/backups/<时间戳>/`,保留最近 10 份;
- 强制改密:默认 admin 账号(及 Bootstrap 初始密码)带 `mustChangePassword` 标记,登录后强制落到改密页、锁住其它功能,改密成功自动解除。

## 二、复查批(同日第二轮合理性复查的修复)

> 上线复查发现的问题,全部修复并进 `reality_e2e_test.go` 断言。

1. **重答检测不认作废卷**(bug):`markDuplicateRegs` 存量循环计入已作废卷 → 重扫替换后再补传会误报「疑似重答」且告警指向死卷,异常清单出现无法裁决的悬案。修复:存量侧跳过 `Voided`(与全系统语义一致:作废卷=不存在)。
2. **强制改密从"前端引导"升级为服务端闸门**:guard 中间件对 `MustChangePassword` 账号只放行 `/auth/password`、`/auth/me`、`/auth/logout`,其余 API 一律 403。置位来源:初始管理员、**管理员重置密码**、**CSV 批量开号的新账号**(已存在账号重导不反复置位)。
3. **匿名阅卷在内嵌报告表破功**:Grader 报告表的考号列随 `anonymous` 开关隐藏(阅卷中打开报告不再等于破匿名)。
4. **PDF 导入分辨率**:拆页目标宽 1600px(≈193dpi,内嵌 300dpi 扫描图被降采样、二维码考号模块处于边缘)→ **2200px**(≈265dpi),渲染 scale 上限 3→4。
5. **manual-scores 限定手工科目**:对扫描考试调用返回 400(原先会误写第 1 题评分,虽有越界兜底但语义错误)。
6. **作废/恢复卷与复核裁决权限收窄**:由 canOpenExam(任课教师即可)收窄到 **建卷人/年级组长/管理员**(与改元数据同口径);前端对应按钮同步门禁,普通教师保留 ⚑ 待复核通道。
7. **成绩条排名/均分改全卷口径**:教师按任教班级过滤导出时,名次与均分仍按全卷计算(单班教师印出的「第 N 名」不再是班内名次,与班主任/组长导出同数字);条面标签明确「年级均分」。
8. **年级总表两处口径**:① 全科缺考(所有科目缺考/不在册)**默认不进排名池**(名次示「未参与」),`absentRank=include` 恢复计 0 垫底旧口径,总表页开关可切;② 响应新增 `totalExams`(分组内全部考试数),账号不可见部分科目时前端提示「总分与排名仅按可见科目计算」。

## 四、遗留大项批(2026-10-25:移动阅卷 / 场次与监考冲突 / 外部备份 / AB 卷 / TWAIN 结论)

1. **手机/触屏阅卷适配**:Grader 新增 ≤860px 响应式布局(上图下操作区、面板底部化、zoom 240vw、toast 适配);
   画笔触屏化(`touch-action` 动态切换 + `pointercancel` 收笔 + 笔迹宽度随画布缩放);
   R/F/G 三个键盘专属动作补触屏按钮(同上分/下份未评/待复核),分数输入条与名册搜索加确认按钮,内嵌报告加关闭按钮。桌面端零影响(媒体查询限定)。
2. **场次表 + 监考冲突检测(场次表制)**:`school.json` 加全校场次表(`GET·PUT /api/v1/school/sessions`,admin 维护,admin.html 组织架构处编辑);
   考试挂场次(建考表单/考试信息面板下拉,非空须在表内);`GET/PATCH /exams/{id}/rooms` 响应附 `conflicts`
   (同日同场次其它考试已指派同一监考的教师清单,只提示不阻断),考场编排页红标 + 冲突面板。无日期/场次不参与。
3. **备份目录可指到外部盘**:`-backup-dir` flag / `OPENGRADE_BACKUP_DIR` 环境变量(缺省 data/backups);
   源/目标分离,目标在源内时防递归快照;单测覆盖外部目录落盘/裁剪/自指跳过/不可写报错。
4. **AB 卷(版式 v3)**:卡面卷种点(A 卡第 1 点实心/B 卡第 2 点实心,OMR 自动识别,与考号通道无关)+
   个性化卡二维码复合内容「考试短号(4)+卷种位+考号」(扫描时自动核对归属,卷种点判不出时冗余兜底,矛盾告警);
   建考上传 B 卷版式+卡面序答案+题序对照(主观题区两版强制一致、客观题集合一致仅序可乱、order 必须为排列);
   判读按卷种选版式、作答入库即归一为规范题号(统计/导出/趋势零改动);卷种判不出 → 客观题暂扣不进统计,
   异常清单「指派 A/B 卷」一键按该卷种从矫正图重读恢复(`POST /exams/{id}/assign-variant`,建卷人/组长/admin);
   `GET /exams/{id}/cards.pdf?variant=A|B` 按名册逐生出个性化卡(可选增强:复合码含考号只能逐生印)。**白卡 AB 流程同样可用**:设计器「卷种」下拉(A/B)导出的母版自带卷种点,`ogctl gen -variant A|B` 同口径 —— 学生手涂考号,卷种点单通道分版,不依赖个性化。e2e:ab_e2e_test.go 全链路。
5. **TWAIN 结论(不写代码)**:浏览器与纯 Go 均无法直连 TWAIN/SANE(需 Windows DLL 或商业 SDK,与零依赖定位冲突);
   社区版量产路线定格为「扫描软件出图/出 PDF → pdf.js 拆页 + 分批接力上传」;驱动直连与热文件夹监听列 EE 候选。
